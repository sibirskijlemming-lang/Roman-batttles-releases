# Roman batttles

Public Windows demo builds of a historical mercenary tactics game: party management, real-time tactical battles with pause, camp and a small world.

**[Download the current Windows build](https://github.com/sibirskijlemming-lang/Roman-batttles-releases/releases/latest/download/Roman-batttles-Windows.zip)**

[Release notes and previous versions](https://github.com/sibirskijlemming-lang/Roman-batttles-releases/releases)

Распакуйте архив целиком в локальную папку и запустите **Play.cmd**. Устанавливать Unity не нужно. Сохранения: **Saves/Campaigns** рядом с игрой. Не запускайте игру внутри ZIP или облачной папки.

Это развивающаяся демоверсия. Цены и баланс черновые. Новые публичные версии выходят по решению автора; автоматических публикаций нет.

This repository distributes playable builds and notes. Game source and private saves are not included. No open-source license is granted by this download.
